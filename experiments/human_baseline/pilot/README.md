# Pilot human baseline

This directory preserves the first human-baseline run, which used the leading
20 test melodies rather than a random sample. The fixed prefix was denser and
more melodic than the full test set, so the experiment was replaced by the
seeded, stratified 40-example subset in `../config.json`.

The files here are historical:

* `transcriptions/` and `timing.csv` are the original hand-written note tables
  and timing log.
* `report.json` and `report.md` are the scores produced from those
  transcriptions.
