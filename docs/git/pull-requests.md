# Pull requests

PR descriptions and merge commit descriptions use the same description and
follow this structure:

```text
<Verb> ..., including:

- ...
```

Each bullet point begins with a capital letter (unless it is escaped in
backticks like `src/...`) and ends with a period.

Merge commit titles start with `[merge]` and end with the PR number:

```text
[merge] refactor(experiments): remove the dataset candidate prefix #20
```
